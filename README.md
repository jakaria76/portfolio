# MD. Jakaria — Portfolio

Personal portfolio of **MD. Jakaria**, Full Stack & Mobile App Developer from Dhaka, Bangladesh.

Built with **Next.js** and **Tailwind CSS**, with light/dark mode, a mobile-first layout and SEO (metadata, sitemap, structured data).

## Run locally

```bash
npm install
npm run dev
```

Then open http://localhost:3000.

## Edit content

All text, projects, skills and links live in one file: `src/data/portfolio.js`.
